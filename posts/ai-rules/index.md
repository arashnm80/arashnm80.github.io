# Rules for AI Agents

The rules AI agents follow when they work on my projects. They bind every agent in every project. A project may add its own rules on top, but never lower these.

## How to use

1. Always read [Development](https://arashnm80.com/ai-rules/development) first. It holds the general rules (R1 to R5) for all work.
2. Then read the page for the kind of task at hand, if one exists.
3. When rules conflict, the development rules win.
